# MEDDYCA

Repositorio del proyecto **MEDDYCA**: aquí vive todo el material de trabajo del
proyecto, con historial de cambios. Piensa en él como el archivo maestro de
MEDDYCA.

> Regla de la casa: este repo es solo para MEDDYCA. EDDYTIONS, RIVEMARKETER y
> EDDYFICATIONS tienen cada uno su propio espacio. Nada se mezcla.

## Estructura

| Carpeta | Qué va aquí |
|---|---|
| `campañas/` | Registro de cada campaña: objetivo, cambios y resultados. Una subcarpeta por campaña, usando `plantilla-campana.md` como base. |
| `copies/` | Textos de anuncios (títulos, descripciones, llamadas a la acción). |
| `creatividades/` | Imágenes y videos para los anuncios. |
| `landing-pages/` | Archivos o notas de las páginas de destino. |
| `scripts/` | Guiones de video o audio. |

## Cómo se usa

1. Todo cambio queda guardado con fecha: si algo se rompe, se puede volver atrás.
2. Cada campaña en META se registra en `campañas/` con **qué se cambió, cuándo y
   por qué** — así el historial explica solo las decisiones.
3. Nada se publica ni se gasta desde aquí: este repo es organización, las
   decisiones de campaña siempre las toma Tony.
